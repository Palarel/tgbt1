# Telegram-магазин цифрового контента

Бот на Python 3.11+, aiogram 3.x и SQLite сканирует локальную папку `ggfiles`,
продаёт фото за 10 Stars и видео за 20 Stars. Каждый пользователь может купить
каждый файл только один раз. История покупок доступна по команде `/purchases`.
Дополнительно доступны базовый архив за 1 000 Stars и FULL PACK из 550 видео
за 2 500 Stars. Пользователю, выбравшему базовый архив, показывается предложение
перейти на FULL PACK.
Команда `/start` показывает каталог, историю покупок и ссылку на поддержку
`[@serbachova](https://t.me/serbachova)`; по индивидуальным вопросам, заказам и
техническим проблемам пользователи могут обратиться к оператору.

## Настройка и запуск (Windows PowerShell)

1. Установите Python 3.11 или новее и создайте бота через [@BotFather](https://t.me/BotFather).
2. В корне проекта скопируйте `.env.example` в `.env` и задайте в `.env` значение
   `BOT_TOKEN`. Не публикуйте `.env`.
3. Установите зависимости и запустите бота:

   ```powershell
   cd "путь\к\ботик"
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python main.py
   ```

   Если PowerShell блокирует активацию виртуального окружения, запускайте напрямую:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

## Каталог файлов

Поместите файлы в папку `ggfiles` в корне проекта. Можно использовать подпапки
`ggfiles\photos` и `ggfiles\videos`, однако бот рекурсивно сканирует все подпапки.
Поддерживаются изображения `.jpg`, `.jpeg`, `.png` и видео `.mp4`, `.mov`
(регистр расширения не важен). Каталог создаётся автоматически, если его нет.
Файлы индексируются при запуске; чтобы добавить или удалить файлы, перезапустите
бота. ID создаётся из относительного пути файла и сохраняется стабильным при
повторном запуске, если путь не меняется.

## Оплата и надёжность

Счета отправляются в валюте Telegram Stars `XTR` с пустым `provider_token`.
Перед подтверждением оплаты проверяются резерв товара (30 минут), наличие файла,
валюта и точная цена. Платежи и каталог хранятся в `shop.sqlite3` (или по пути
из `DATABASE_PATH`). Ошибки логируются в консоль; при проблеме с файлом после
оплаты бот сообщает покупателю обратиться в поддержку.
Оплата архивных тарифов проводится отдельными счетами Telegram Stars; ссылка
Mega выдаётся только после проверки успешного платежа. В соответствии с выбранным
при настройке вариантом выдачи ссылка отправляется покупателям обоих тарифов.
Оплаченные архивные заказы сохраняются в таблице `package_orders` и отображаются
в истории `/purchases`, где покупатель может повторно получить свою ссылку.

`bot.py` оставлен как совместимый способ запуска: `python bot.py`.

## Панель администратора

Доступ администратора разрешён аккаунту Telegram с username `@serbachova`
(регистр и начальный `@` не учитываются). При запуске `/start` этот аккаунт
увидит кнопку «⚙️ Админ-панель»; также панель открывается командой `/admin`.
Для других аккаунтов команда `/admin` вернёт отказ и текущий user_id для проверки.

В панели доступны SQLite/file-system health check, тестовая отправка случайного
фото или видео, пересканирование `ggfiles` без удаления истории, а также
статистика последних пяти транзакций. Для ручной выдачи нажмите «Выдать контент»,
укажите известный боту `@username` или user ID, выберите товар из каталога либо
загрузите фото/видео и подтвердите отправку. Бот запоминает пользователя при
любом сообщении или нажатии кнопки; написать первым пользователю, который ни разу
не запускал бота, Telegram не позволяет. Ручные выдачи сохраняются в таблице
`manual_grants`. При первой ручной отправке каталожного файла полученный от Telegram
`file_id` сохраняется в каталоге, и следующие выдачи используют его без повторной
загрузки файла. Временные сетевые/серверные ошибки и FloodWait обрабатываются одной
автоматической повторной попыткой; состояние сценария очищается по завершении.
Команда `/purchases` показывает историю покупок текущего пользователя.
Видео при покупке, ручной выдаче, тестовой отправке и предзагрузке отправляются
с кликабельной ссылкой на `https://t.me/gerogroup`; кэшированный Telegram `file_id`
используется повторно, а перед видео бот показывает статус `upload_video`.

## Быстрая отправка и прогрев кэша

Для предварительной загрузки добавьте в `.env` параметр `STORAGE_CHANNEL_ID`
со значением ID закрытого Telegram-канала (обычно начинается с `-100...`).
Добавьте бота в канал с правом публикации сообщений, затем нажмите в админке
«Прогреть кэш (Предзагрузка)». Бот отправит туда файлы без сохранённого
Telegram `file_id` и запишет идентификаторы в SQLite. При последующей доставке
бот переиспользует эти идентификаторы; если кэш пуст, файл отправляется с диска,
а полученный `file_id` сохраняется автоматически.

Кэширование убирает повторную загрузку медиа с сервера бота, но не гарантирует
фиксированную задержку менее 0,5 секунды: фактическое время ответа зависит от
сети и Telegram API. Пул aiohttp-соединений настроен на 100 подключений; общий
сетевой таймаут HTTP-сессии — 60 секунд, а таймаут long polling — 30 секунд.
